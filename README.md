# ระบบจองคิวออนไลน์ — รพ.สต.บ้านหนองครกใต้

หน้าจองเปิดในแอป LINE (LIFF) จากริชเมนู · **แยกหมวดตามแผนกตั้งแต่หน้าแรก** · **ไม่จำกัดจำนวนคิว**
หลังบ้านใช้ Google Sheets + Apps Script + LINE Messaging API — ไม่มีค่าเซิร์ฟเวอร์รายเดือน

## ไฟล์ในโปรเจ็ค

```
line-oa-arm/
├── config.js            ⭐ ตั้งค่าทุกอย่างที่นี่ที่เดียว (แผนก เวลา วันเปิด LIFF_ID API_URL)
├── assets/theme.css        ธีมเขียวมิ้น–ขาว ใช้ร่วมกันทุกหน้า
├── liff/index.html         หน้าจองสำหรับประชาชน
├── staff/index.html        หน้าเจ้าหน้าที่ (ดูคิว เรียกคิว เช็คอิน)
├── gas/Code.gs             หลังบ้าน — วางใน Google Apps Script
├── gas/appsscript.json     ตั้งค่าโปรเจ็ค Apps Script
└── prototype/index.html    ตัวอย่างหน้าจอไว้ดูภาพรวม (ไม่เกี่ยวกับระบบจริง)
```

## แผนกที่เปิดให้จอง

| แผนก | เลขคิว | วันเปิด | ช่วงเวลา |
|---|---|---|---|
| แพทย์แผนไทย | ท-001 | จันทร์–ศุกร์ | 09–10 · 10–11 · 11–12 · 13:30–14:30 · 15–16 |
| ทันตกรรม | ฟ-001 | อังคาร · พฤหัสบดี · ศุกร์ ⚠️ *รอยืนยัน* | 09–10 · 10–11 · 11–12 · 14–15 · 15–16 |

แก้วันเปิด / ช่วงเวลา / รายการบริการได้ที่ [`config.js`](config.js) — ถ้าแก้วันเปิดหรือช่วงเวลา
ต้องแก้ตัวแปร `DEPTS` ที่หัวไฟล์ [`gas/Code.gs`](gas/Code.gs) ให้ตรงกันด้วย

# สิ่งที่ต้องทำ ทีละขั้น

ทำตามลำดับ ใช้เวลารวมประมาณ 1 ชั่วโมง ทุกอย่างฟรี

## ☐ ขั้นที่ 0 · ลองเปิดดูก่อน (2 นาที)

ดับเบิลคลิก `liff/index.html` และ `staff/index.html` เปิดในเบราว์เซอร์ได้เลย
ตอนนี้ `config.js` ตั้ง `DEMO: true` ไว้ — ใช้ข้อมูลตัวอย่าง ไม่บันทึกอะไรจริง
ถ้าหน้าตาหรือรายการบริการยังไม่ถูก แก้ที่ `config.js` ก่อน แล้วค่อยทำขั้นถัดไป

## ☐ ขั้นที่ 1 · สร้างฐานข้อมูล (Google Sheets + Apps Script)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อ `ฐานข้อมูลคิว รพ.สต.บ้านหนองครกใต้`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาทั้งหมดจาก [`gas/Code.gs`](gas/Code.gs) ลงไป
4. กด 💾 บันทึก แล้วเปิดค้างไว้ — จะกลับมาที่หน้านี้อีกในขั้นที่ 4

## ☐ ขั้นที่ 2 · เปิด Messaging API บน LINE OA เดิม

`LINE Official Account Manager` → เลือกบัญชี → **ตั้งค่า** → **Messaging API** → **ใช้งาน Messaging API**

- เลือกหรือสร้าง **Provider** — ตั้งชื่อเป็นชื่อหน่วยงาน
  > ⚠️ **จำ Provider ตัวนี้ไว้** ขั้นที่ 3 ต้องใช้ตัวเดียวกัน ถ้าใช้คนละตัว LIFF จะดึงข้อมูลผู้จองไม่ได้
- ทำเสร็จจะได้ **Channel secret**

จากนั้นไปที่ `LINE Developers Console` → Provider เดิม → ช่อง Messaging API → แท็บ **Messaging API**

- หา **Channel access token (long-lived)** → กด **Issue** → คัดลอกเก็บไว้ ➊
- ที่หน้าเดียวกัน ปิด **Auto-reply messages** และ **Greeting messages** (ถ้าไม่ต้องการให้บอทตอบอัตโนมัติทับ)

## ☐ ขั้นที่ 3 · สร้าง LIFF (หน้าจอง)

`LINE Developers Console` → **Provider เดิม** → **Create a new channel** → **LINE Login**

- Channel name: `จองคิว รพ.สต.บ้านหนองครกใต้`
- App types: ติ๊ก **Web app**
- สร้างเสร็จ → แท็บ **Basic settings** → คัดลอก **Channel ID** เก็บไว้ ➋
- ไปแท็บ **LIFF** → **Add**
  - Endpoint URL: ใส่ `https://example.com` ไปก่อน (แก้ทีหลังในขั้นที่ 6)
  - Size: **Full**
  - Scopes: ติ๊ก **profile** และ **openid**
- จะได้ **LIFF ID** หน้าตา `2001234567-AbCdEfGh` เก็บไว้ ➌

## ☐ ขั้นที่ 4 · ต่อ Apps Script เข้ากับ LINE

กลับไปหน้า Apps Script แล้วทำ 3 อย่าง

**4.1 ใส่ค่าลับ** — ⚙️ **Project Settings** → เลื่อนลงหา **Script Properties** → **Add script property**

| Property | Value |
|---|---|
| `CHANNEL_ACCESS_TOKEN` | ➊ จากขั้นที่ 2 |
| `LOGIN_CHANNEL_ID` | ➋ Channel ID ของ **LINE Login** channel (ไม่ใช่ของ Messaging API) |
| `STAFF_KEY` | ตั้งรหัสผ่านหน้าเจ้าหน้าที่เอง ให้เดายาก |

> 🔒 ค่าพวกนี้เก็บที่นี่ที่เดียว **ห้ามใส่ใน `config.js`** เพราะไฟล์นั้นใครก็เปิดอ่านได้จากเบราว์เซอร์
> ใครได้ `CHANNEL_ACCESS_TOKEN` ไป จะส่งข้อความในนามหน่วยงานได้ทันที

**4.2 รัน `setup()` หนึ่งครั้ง** — เลือกฟังก์ชัน `setup` ที่แถบด้านบน → กด **Run**
Google จะขออนุญาตเข้าถึงข้อมูล → **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow**
(ขึ้นว่า unsafe เพราะเป็นสคริปต์ที่เขียนเอง ไม่ได้ผ่านการรับรองจาก Google — ปกติ)

เสร็จแล้วจะเห็นชีต `bookings` กับ `patients` โผล่ขึ้นมา และตั้งเวลาส่งแจ้งเตือน 19:00 ทุกวันให้อัตโนมัติ

**4.3 Deploy** — **Deploy** → **New deployment** → ⚙️ เลือก **Web app**

- Execute as: **Me**
- Who has access: **Anyone**
- กด **Deploy** → คัดลอก **Web app URL** ที่ลงท้าย `/exec` เก็บไว้ ➍

## ☐ ขั้นที่ 5 · อัปหน้าเว็บขึ้นอินเทอร์เน็ต

LIFF ต้องเป็น `https://` เปิดจากไฟล์ในเครื่องไม่ได้ · โปรเจ็คนี้เตรียม `vercel.json` ไว้ให้แล้ว

### วิธีที่ 1 — Vercel (แนะนำ)

เปิด Terminal แล้วรัน 2 คำสั่งนี้ในโฟลเดอร์โปรเจ็ค

```bash
cd ~/Desktop/line-oa-arm
npx vercel --prod
```

ครั้งแรกจะให้ล็อกอิน (อีเมลหรือ GitHub) แล้วถามไม่กี่ข้อ — กด Enter ผ่านได้หมด

| คำถาม | ตอบ |
|---|---|
| Set up and deploy? | `y` |
| Which scope? | เลือกบัญชีตัวเอง |
| Link to existing project? | `n` |
| Project name? | `line-oa-arm` (หรือกด Enter) |
| In which directory is your code located? | `./` |
| Want to modify settings? | `n` |

เสร็จแล้วจะได้ URL เช่น `https://line-oa-arm.vercel.app`

- หน้าจอง → `https://line-oa-arm.vercel.app/liff/` (เปิดโดเมนเปล่าก็เด้งมาหน้านี้)
- หน้าเจ้าหน้าที่ → `https://line-oa-arm.vercel.app/staff/`
- ตัวอย่างหน้าจอ → `https://line-oa-arm.vercel.app/prototype/`

**แก้ไฟล์ทีหลังแล้วอัปใหม่** — รัน `npx vercel --prod` ซ้ำในโฟลเดอร์เดิม ได้ URL เดิม
(เช่น ตอนแก้ `config.js` ในขั้นที่ 6 ต้องรันซ้ำอีกครั้ง)

> `vercel.json` ตั้งไว้ให้แล้ว: เปิดโดเมนเปล่าเด้งไปหน้าจอง, ไม่ให้ Google เก็บหน้าเจ้าหน้าที่ไปทำดัชนี,
> และไม่ cache `config.js` เพื่อให้แก้ค่าแล้วมีผลทันที · `.vercelignore` กันไม่ให้อัปโฟลเดอร์ `gas/` ขึ้นเว็บ

### วิธีที่ 2 — Netlify Drop (ไม่ต้องใช้ Terminal)

เปิด `app.netlify.com/drop` แล้วลากโฟลเดอร์ `line-oa-arm` ทั้งโฟลเดอร์ไปวาง ได้ URL ทันที
ข้อเสีย: อัปใหม่ทุกครั้งต้องลากใหม่ และได้ URL ใหม่ถ้าไม่ผูกบัญชี

### วิธีที่ 3 — GitHub + Vercel

push ขึ้น GitHub แล้วกด Import ที่ `vercel.com/new` — หลังจากนั้นแก้โค้ดแล้ว push
Vercel จะ deploy ให้เองอัตโนมัติ เหมาะถ้าจะดูแลระยะยาว

## ☐ ขั้นที่ 6 · เชื่อมทุกอย่างเข้าด้วยกัน

**6.1** แก้ [`config.js`](config.js) 3 บรรทัด แล้วอัปโหลดใหม่

```js
LIFF_ID: '2001234567-AbCdEfGh',                          // ➌
API_URL: 'https://script.google.com/macros/s/..../exec', // ➍
DEMO: false,                                             // ← เปลี่ยนเป็น false
```

**6.2** กลับไป `LINE Developers Console` → LIFF → แก้ **Endpoint URL** เป็น `https://xxxx.netlify.app/liff/`

## ☐ ขั้นที่ 7 · เปลี่ยนปุ่มในริชเมนู

`LINE Official Account Manager` → **ริชเมนู** → ปุ่ม **จองคิวรับบริการ**
เปลี่ยนจากลิงก์ Google Form เป็น

```
https://liff.line.me/2001234567-AbCdEfGh
```

(ใช้ LIFF ID ➌ ของตัวเอง) แล้วกดบันทึก

## ☐ ขั้นที่ 8 · ทดสอบจริง

1. เปิดแชท LINE OA ด้วยมือถือตัวเอง กดปุ่ม **จองคิวรับบริการ**
2. จองคิวทดสอบ 1 คิว → ต้องได้บัตรคิวเด้งเข้าแชท
3. เปิด Google Sheet → ต้องเห็นแถวใหม่ในชีต `bookings`
4. เปิด `https://xxxx.netlify.app/staff/` ใส่ `STAFF_KEY` → ต้องเห็นคิวที่เพิ่งจอง
5. กด **เรียกคิว** → มือถือต้องได้ข้อความ "ถึงคิวของท่านแล้ว"
6. ลบแถวทดสอบออกจาก Sheet

## ☐ ขั้นที่ 9 · ยื่นขอบัญชีรับรอง (ทำคู่ขนานได้)

ตอนนี้ LINE OA ยังขึ้นแถบ *"บัญชีนี้ไม่ได้เป็นบัญชีรับรอง"* — ระบบนี้ขอเลขบัตรประชาชน
หน่วยงานจึงควรยื่นขอ **บัญชีรับรอง (โล่น้ำเงิน)** ที่ OA Manager → ตั้งค่า → ข้อมูลบัญชี
ใช้เอกสารหน่วยงาน ฟรี ประมาณ 10 วันทำการ

## ข้อมูลที่ระบบเก็บ

**ชีต `bookings`** — 1 แถวต่อ 1 คิว
`id · createdAt · userId · displayName · dept · service · date · slot · queueNo · name · idCard · tel · right · note · status · calledAt · updatedAt`

**ชีต `patients`** — 1 แถวต่อ 1 คน ใช้เติมฟอร์มให้อัตโนมัติในการจองครั้งถัดไป
`userId · name · idCard · tel · right · consentAt · updatedAt`

`status` มีค่า `booked` (รอเรียก) · `checkin` · `done` · `noshow` · `cancelled`
ไม่มีการลบแถว ยกเลิกคิวคือเปลี่ยน status เป็น `cancelled` เพื่อให้ตรวจย้อนหลังได้

## เรื่องความปลอดภัยที่ทำไว้

- หน้าเว็บส่ง **LINE ID token** มาให้หลังบ้านตรวจกับเซิร์ฟเวอร์ LINE ทุกครั้ง ไม่เชื่อ `userId` ที่ส่งมาจากเบราว์เซอร์
- เลขบัตรประชาชนตรวจ checksum 13 หลักก่อนบันทึก และแสดงผลแบบปิดบังเมื่อเติมฟอร์มครั้งถัดไป
- กันจองซ้ำ: คนเดิม แผนกเดิม วันเดียวกัน จองได้คิวเดียว
- กันจองย้อนหลัง จองเกิน 14 วัน และจองวันที่แผนกไม่เปิด — ตรวจซ้ำที่ฝั่งเซิร์ฟเวอร์ ไม่ได้เชื่อหน้าเว็บอย่างเดียว
- ยกเลิกคิวได้เฉพาะเจ้าของคิวเท่านั้น
- หน้าเจ้าหน้าที่ต้องใช้ `STAFF_KEY`

## สิ่งที่ยังไม่ได้ทำ

- ยังไม่ได้ยืนยัน **วันเปิดทำการของทันตกรรม** — ตอนนี้ตั้งไว้ อังคาร/พฤหัส/ศุกร์ ที่ `config.js` และ `gas/Code.gs`
- ยังไม่มีหน้าตั้งวันหยุดราชการแบบกดเลือก — ตอนนี้ใส่เป็นวันที่ในช่อง `HOLIDAYS` ของ `config.js`
- ยังไม่มี QR ในบัตรคิว (เจ้าหน้าที่ค้นด้วยชื่อ/เลขคิวในหน้าเจ้าหน้าที่แทน)
- หน้าเจ้าหน้าที่จำรหัสผ่านไว้ในเบราว์เซอร์เครื่องนั้น เหมาะกับคอมพิวเตอร์ของหน่วยงาน ไม่ควรใช้บนเครื่องสาธารณะ
